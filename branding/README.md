# ZAOD OS branding

Is folder me ZAOD OS ke open-source brand assets aur theme metadata rehte hain.

## Design approach

- Google Fonts: open-source fonts ke liye `Outfit` aur `Roboto`
- Lucide: MIT-licensed Lucide icon set
- Color system: Material 3-inspired neutral, primary, secondary, aur tonal surface tokens
- Desktop: proprietary desktop ka direct copy nahi; open-source Plasma/XFCE ke upar naya original ZAOD desktop identity

Actual font aur icon files internet se official packages/repositories me se install ki jayengi taake licenses saath rahein.
